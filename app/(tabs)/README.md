# Tabs

Ba tab feature trỏ tới screen thuộc owner tương ứng:
- `lessons.tsx` → `src/features/lessons/screens/LessonsScreen.tsx`
- `practice.tsx` → `src/features/practice/screens/PracticeScreen.tsx`
- `tutor.tsx` → `src/features/tutor/screens/TutorScreen.tsx`

Các screen hiện render trống để không lộ note/dev text trên web public. Home/Profile giữ nguyên.
