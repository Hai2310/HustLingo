# Vocabulary illustrations

Created on 2026-11-04 with the built-in imagegen tool for HustLingo. Seven original illustrations; optimized as 960 × 640 JPEG assets for Expo / React Native. No external image server is needed. PNG originals are preserved in the image generation output directory.

The illustrations represent topic scenes. A word card labels an illustration as **TOPIC SCENE**, so a family scene is not presented as an exact picture definition of one family member. Only explicitly mapped terms receive contextual pictures. Other words use a styled letter tile. Source vocabulary and database rows are unchanged.

Runtime mapping: `src/features/lessons/data/vocabulary-artwork.ts`.
