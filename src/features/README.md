# HustLingo feature ownership

Mỗi thành viên chỉ làm trong feature của mình để giảm conflict Git.

- `lessons/`: Huy Bài học.
- `practice/`: Dương Luyện tập.
- `tutor/`: Khánh Gia sư AI.
- `backend/`: Hải tài liệu phạm vi Backend/Core; code backend thật vẫn nằm ở `src/services`, `src/contexts`, `supabase`.

Ba tab public hiện vẫn trống. Khi từng feature sẵn sàng, code UI bắt đầu tại `screens/*Screen.tsx`.
